# Four queries the guard flagged on a green main once CI came back from the
# billing outage. Each call path was read before it was listed here; the
# reason names the guard, not the table.
FindLatestConversationByContact  # conversations: scoped by channel_id, and the channel is resolved from the inbound webhook token — the tenant boundary of that pipeline. Reopen() then writes with the row's own account_id.
ClaimLeadForSend  # leads: the id reaches it only from ApproachUseCase.ApproveSend, after ownedLeadAndFunnel(accountID, leadID) proved the lead belongs to the caller.
ListConversationMedia  # messages: HandleListConversationMedia refuses with 404 unless convRepo.GetByID(convID, accountID) returns the conversation first.
GetUserSessionInvalidatedAt  # users: the id is the subject of the caller's own signed JWT; there is no cross-account read to make.
